# 自动赛前装备与场外动态

2026-10-14：新闻来自 F1 与车队官方公开文章，提取原文中的车手装备、特别头盔、服装、赛车涂装、好友互动、兴趣爱好和公开社媒动态。每条保留原报道、发布日期，存在可读取的社媒原帖时附原帖链接；不会假装已接入 Instagram/X 的完整私有 API。无法访问、日期不明或摘要无原文依据的内容保留旧记录并重试。

`.github/workflows/editorial-news.yml` 每4小时检查官方新闻入口，每次最多12篇，使用 DeepSeek Flash 输出短摘要。车手/车队ID按F1DB目录校验；摘要必须提供可在原文找到的短证据，额外出现的车手姓名被拒绝。这些检查不是完整的事实核验，自动稿仍应人工审阅。首批内容已对照官方来源修正，图片也已实际查看。

独立数据分支 `codex/editorial-news` 保存 `news.json` 和压缩照片，不触发网站部署。页面服务端每分钟检查数据，有故障时保留上次成功内容和随网站附带的首批数据。照片压缩为 WebP，最大1200px、180KB，保留来源、尺寸和实际字节数，页面使用懒加载。正文内直接显示，不使用折叠、轮播或展开按钮。

涂装从同一批新闻数据写入独立 `liveries` 列表。仅有明确车队、车型、事件年份和分站时才关联；不会把新加坡特别涂装标成美国站涂装。头盔和服装不写进赛车涂装记录。最近45天公开动态显示在实时页，历史装备与涂装按其分站留档。

2026-10-14 分站展示修正：实时页赛前区按当前赛程的年份及分站 ID 精确筛选，上一站和已过期内容不能进入下一站。未绑定分站的公开场外故事单列“近期车手动态”，分站不明的装备、涂装不作为本站内容展示；本站无确认消息时显示明确空状态。官方车队文章 URL 指定的年份和分站优先于模型推断，冲突时不登记涂装。回归测试覆盖新加坡到美国的切换、错站推断、无分站装备、未来/过期稿及休赛期。实时页新闻全部同级瀑布卡片，无首条置顶；全年分站横条取消滚轮转横向处理。
