# PITWALL · F1 百科与实时数据（Demo）

以 **年份 × 赛道 × 车手 × 车队** 四个基础单元构建的 F1 信息站（赛车挂在「车队 × 年份」上）。任何一个对象页都是这个数据立方体的一个切片：固定一个维度，其余三个维度可以切换视图、筛选、透视，任意格子都能下钻到「那一年在那条赛道」的单场页。

## 在线访问

- 网站：https://pitwall-f1-nine.vercel.app
- 公开仓库：https://github.com/championwang00/pitwall-f1

## 运行

```bash
npm install
npm run dev        # http://localhost:3210
```

需要 Node 22+（使用内置 `node:sqlite` 读取 F1DB）。

## 页面

| 路径 | 内容 |
|---|---|
| `/` | 下一站：真实遥测重建的 3D 赛道、倒计时、各节时间（本地时区）、积分塔；上一站领奖台；本季「车手 × 分站」矩阵；这条赛道的过去；77 个赛季条带 |
| `/live` | 实时计时（OpenF1，`?year=2023…` 可回放往年任意一节）：计时塔、3D 赛道车位、两位车手圈速与差距对比、赛事指令、天气、车队无线电，以及随对比车手切换的「解说卡」（两人在本赛道的历史与故事线）；无比赛时自动进入最近一节的回放 |
| `/brief` | **本站解说手册**：赛道要点、上一次在这里、冠军形势、22 位车手各自在这条赛道的历史（逐年名次）、车队战绩、赛季看点；可打印 / 存 PDF。`?year=&round=` 可看任意一站 |
| `/seasons/[year]` | **历史**：左侧常驻年份栏（按规则时代分组，色块 = 当年车队冠军），切换年份保留当前标签页。标签：**赛历**（默认；当年为实时赛历：下一站倒计时与各节时间、最新一站领奖台、逐站卡片，2023 年起每站可直接进入计时回放，更早年份为档案；全年行程地球仪与日历订阅）· **积分榜**（冠军之争走势、两个锦标赛、车手 × 分站矩阵）· **时代**（规则时代、关键规则、本时代各赛季冠军）· **赛道**（当年的赛道、各自第几次举办、首次登场 / 回归 / 告别）· **车手**（新秀、转队、领奖台）· **车队**（赛车、引擎、车手阵容）。`/seasons` 打开当年，`/calendar` 跳转到这里 |
| `/circuits/[id]` | 3D 赛道、历届冠军（按年代）、在这条赛道上谁最强（按车手 / 车队透视）、核实过的历史时刻 |
| `/drivers/[id]` | 生涯「年份 × 车队 × 赛车」条带、全部比赛透视（按年份 / 赛道 / 车队 / 矩阵）、高光时刻与趣闻（附来源）、家族与队友 |
| `/teams/[id]` | 年份 × 车手 × 赛车 × 引擎、前身与后继、全部比赛透视、车队档案 |
| `/cars/[id]` | 官方侧视图 + 气流可视化（2026 赛车可切换直道 / 弯道模式）、技术规格、逐场成绩、同队前后代 |
| `/races/[year]/[round]` | 「那年那站」：维基百科综述、百科中关于这一站的记载、正赛 / 排位 / 冲刺 / 进站、同赛道前后年份与各维度跳转 |
| `/compare?a=&b=` | 任意两位车手：生涯对比、同场交锋逐场、在共同赛道上的胜场 |

每个对象页（车手 / 车队 / 赛道 / 年份 / 单场）英雄区下方都有 **「解说要点」**：一部分由 F1DB 实时计算（去年这里谁赢、胜场王、现役车手在此战绩、杆位转化率、最大逆转、里程碑、队内对比、下一站战绩……），另一部分是研究代理全网检索并逐条核实的故事线与冷知识（`content/notes.*.json`，每条附来源）。可一键复制全部要点。

**四个基础单元处处互链**：任何页面上出现的车手、车队、赛道、年份都是链接，鼠标停留会弹出简介卡（照片 / 车标 / 赛道图、关键数据、一句话简介）；正文里的中文人名、车队名、赛道名、「2008年巴西大奖赛」这类说法也会自动识别成链接。展示人物时一律「头像 + 名字」；冠军与荣誉用月桂徽章表示（金 = 冠军、银 / 铜 = 亚季军、红 = 杆位 / 领跑、紫 = 最快圈 / 纪录、车队冠军用车队色）。

所有对象页的筛选状态都写进 URL（如 `/drivers/lewis-hamilton?circuit=silverstone&view=year`），可直接分享。⌘K 或 `/` 打开全局搜索（中英文均可）。

## 解说员怎么用

1. **赛前**：打开 `/brief`（首页「本站解说手册」）。先看赛道要点与纪录簿，再看「每位车手在这条赛道」——出赛、胜场、领奖台、逐年名次和一句话故事线，点「打印 / 存为 PDF」就是一份纸质手卡。
2. **比赛中**：打开 `/live`。点计时塔任意两行设为 A / B，下方立刻出现两人的圈速、差距曲线，以及「解说卡」（两人在本赛道的历史、各自的故事线、赛道要点）。
3. **临场查询**：⌘K 或 `/` 输入中文或英文名，直接跳到任意车手 / 车队 / 赛道 / 年份；每个页面顶部的「解说要点」可一键复制。矩阵或逐场条里的任意一格都能进入「那一年在那条赛道」。

## 数据

- **F1DB**（`data/f1db.db`，1950 → 2026 第 16 站，CC BY 4.0）：比赛、成绩、积分、底盘、引擎、赛道布局。`npm run update-data` 拉取最新版本（带 SHA-256 校验）。
- **OpenF1**：赛程各节时间、实时 / 回放计时、遥测坐标（3D 赛道由排位赛最快圈的位置数据重建，见 `data/tracks/`，`npm run tracks` 可重建）。
- **MultiViewer 赛道 API**（`api.multiviewer.app`，公开、无鉴权，**只在构建期访问**）：弯心位置与编号。`npm run corners`（`scripts/build-corners.mjs`）把弯心吸附到 `data/tracks` 的遥测圈，写入 `data/corners/`；同一脚本从 OpenF1 取该圈的 S1/S2/S3 边界与弯心最低速度 / 挡位（直播时段 OpenF1 返回 401，脚本跳过并保留弯角）。**`npm run tracks` 之后必须再跑 `npm run corners`**。弯角中文名与注释是人工策展的 `content/corners.json`；页面渲染时只读这两个文件，不联网。
- **Wikipedia REST**：单场综述（中文优先）、历史车手与赛车照片（`data/wiki.json` 由 Jolpica 的维基链接映射而来）。
- **中文译名**：人工核实的译名优先；其余车手 / 车队 / 赛道取中文维基条目按大陆用语转换后的标题（`data/zh-names.json`，`npm run zh-names` 重建）；没有通行译名的保留原文。
- **`content/*.json`**：车手 44 位、车队 28 支、赛车 33 台、赛道 50 条、9 个规则时代的中文档案；另有解说素材 `notes.*.json`（赛道 147 条、车手 137 条、车队 64 条、赛季 198 条，偏重 2025–2026 的最新事件）。合计 1313 条，每条附来源链接，数字与 F1DB 交叉核对；来源互相矛盾或无法在页面上找到的说法已删除。`node --no-warnings scripts/validate-content.mjs` 可重新核对所有引用。

## 设计

对标 formula1.com：深色刊头与斜纹、暖纸色正文、车队色半调纹理（这里是 WebGL 着色器，跟随鼠标光源）、Formula1 字体只用于拉丁标题与英雄数字，数据用 Titillium Web，中文用思源黑体。WebGL：3D 遥测赛道（每条赛道按自身真实落差自适应放大：斯帕 102 米放大约 2 倍，平坦的街道赛如新加坡 5 米放大约 19 倍，页面上标注真实落差与放大倍数）、车队色半调场、全年行程地球仪、赛车气流。页面切换使用 React `<ViewTransition>`（车手卡片 → 车手页、赛车 → 赛车页、首页赛道 → 赛道页为共享元素变形）。

过程记录见 `docs/design-log.md`；早期三个发散方向保留在 `/poc/a`、`/poc/b`、`/poc/c`。

## 注意

- 非官方项目，与 Formula 1 / FIA 无关联。车手、车队、赛车、赛道图片直接引用 formula1.com 媒体服务器（未转存）；Formula1 字体通过同域路由代理；本地缓存在 `.cache/`、云端缓存在 `/tmp`。第三方品牌、字体、图片与起跑音效不属于项目代码的授权；商业使用需另行确认权利。
- OpenF1 的实时数据在比赛进行中可能需要付费授权；未授权时页面会提示并回退到最近一节已完成的会话回放。
- 日历订阅地址跟随访问域名，线上订阅可持续使用，本地订阅依赖本机服务。

## 部署

Vercel 使用 Node 22；数据库与 JSON 内容由 Next 文件追踪显式打包。云端临时缓存写入 `/tmp/pitwall`。本地缓存、设计评审输出与开发器配置不提交。GitHub 推送可触发 Vercel 自动部署。

起跑灯录音来源与处理见 `public/sounds/f1-start-light.source.md`；引擎录音为 rfhache 的 F1 BR 06 Engine Starts 2（CC BY 4.0），改编与归属见 `public/sounds/f1-engine-launch.source.md`。项目为非官方展示，不拥有 F1 品牌、字体与媒体资产。车模功能暂不接入。

云端无线电转录可读取已缓存的内容；新音频的本地 Whisper 转录需要 Python、ffmpeg 与模型，Vercel 当前不提供该本机环境。
